Components:
•	CustomButton: Boton amarillo común de bordes redondeados.
•	Header: Cabecera de todas las paginas por defecto y con un combo box para las sucursales. El combo box refrescará la pagina
•	Navbar: Barra de navegación personalizada
•	Footer: Pie de pagina común en todas las paginas y el símbolo de marca registrada.
•	Boton rojo denegar
•	Boton verde aceptar
•	Botón azul editar o ver
•	Carrusel: Componente carrusel arrastrable
•	CarruselComida: Carrusel con 4 combos importantes de comida.
•	MovieCard: Tarjeta de las películas con toda la información general
•	ComidaCard: Tarjeta de comida con botón para agregar item o quitar item.
•	SucursalCards: Carta de sucursal (opcional)

Pages
Home: Consume carrusel, movieCards y muestra el carrusel con las peliculas y debajo de estes las cards con las características de las películas.
Sucursal (opcional, dejar para el final)
Iniciar sesión: pagina que pida datos al usuario y botones para crear cuenta e iniciar sesión.
Tienda: Permite comprar comida por plata.
Canjear puntos (Usuario): Pagina copia del candybar pero con puntos
Administrador (admin): Pagina privada que solo puede ver el admin si inicio sesión con determinada cuenta y pueda quitar o agregar películas y sus respecticas características y los empleados.
Carrito de compra (Usuario): Es un botón en el header para abrir el carrito, muestre el total a pagar y el ingreso de los datos de la tarjeta.
Gestion de cuenta: Permite cambiar los datos del usuario.
Edicion de productos (empleado): Pagina del empleado donde puede cambiar precio de los combos.
